## Publier avec GitHub Pages

Dans GitHub : **Settings → Pages → Deploy from a branch → main → /(root) → Save**. L'adresse attendue est https://cosscoll.github.io/Pack-Proc-dures-Pro/ , après activation et déploiement réussis.

Les pages et mises à jour de sprint doivent présenter uniquement des éléments de pilotage publics et vérifiés, sans données personnelles ni contenu privé. La présence des fichiers dans le dépôt ne prouve pas à elle seule leur disponibilité publique.

## Garde-fous de qualité (22 octobre 2026)

- Les **quatre poses originales** de la clé 3D et leur interpolation lente sont protégées par un test : on adapte les colonnes de texte et les marges à la clé, jamais l'inverse.
- Un contrôle navigateur vérifie la lisibilité en plusieurs positions de défilement du manifeste, de l'offre et du pied de page sur ordinateur, tablette et mobile.
- Le menu et les liens de la procédure gratuite restent utilisables même si JavaScript ne charge pas.
- Toujours vérifier la publication GitHub Pages avant d'annoncer la livraison ; pas de paiement actif.
